Ansible Basics – A Quick Visual Guide
 
simple visual to understand how Ansible works at a basic level. 🔁

🔹 Task Execution Methods:

 1️⃣ Module – Single task execution (ex: ping, user, file)

 2️⃣ Playbook – Multiple tasks written in YAML format

🎨 Color Output Guide:

 🔴 Red – Error

 ⚪ Grey – Successfully executed

 🟢 Green – No changes needed

🔧 Common Modules:

 📶 ping – Test connectivity

 👥 group – Add/remove group

 👤 user – Add/modify/delete users

 📁 file – Create files/directories

 📋 copy – Copy files/directories

🛠️ User Management Syntax:

 Define user attributes like:

name, uid, shell, password, group, groups

📌 State Parameter:

present – Create

absent – Remove

🔐 These simple modules are powerful when automating system tasks — all part of learning to manage infrastructure the smart way.
