YAML is everywhere in DevOps — from Kubernetes configs to CI/CD pipelines.

But YAML isn’t a programming language. It’s just structured data. And once you know the 6 building blocks, it gets easy.

Here’s what each part does — and why it matters:

1. Scalars  
These are single values: strings, numbers, booleans. They hold the actual data.

2. Lists (Arrays)  
Use dashes to make a list. Great for things like container names or steps in a job.

3. Nested Lists  
Lists inside lists. Useful when you need grouped steps or multi-level data.

4. Dictionaries (Objects)  
Key-value pairs. Think of them like JSON objects. They describe one thing with many details.

5. Nested Dictionaries  
Objects inside objects. This is how you model real-world things like addresses or configs.

6. Comments  
Start with `#`. Use them to explain your YAML — your future self will thank you.

Learn these, and you’ll read 90% of YAML files with ease.
