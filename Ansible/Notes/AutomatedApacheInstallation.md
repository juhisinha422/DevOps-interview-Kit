🚀 Automated Apache Installation with Ansible! 🔧🖥️

wrote and executed an Ansible playbook to install the Apache web server (httpd) on a remote host grouped under web.

📄 Playbook Name: pkg.yml

 ✅ Target Group: web

 🔍 Modules Used:

yum for package management

become: yes for privilege escalation

📦 The playbook ran smoothly—no unreachable or failed nodes, and Apache was installed successfully!

🔁 This is a crucial part of configuration management and system automation — one of the core skills in DevOps practices.

🛠️ Skills Practiced:

YAML syntax and indentation
Inventory targeting

Ansible modules for package management
SSH-based orchestration
