(1) Subnets are strategic

 Dividing a VPC isn’t just organization - it determines availability and fault tolerance.

(2) NAT Gateway costs can add up

 Outbound internet access for private subnets is useful but can rack up charges fast.

(3) Internet Gateway is essential for public access

 Without it, your instances won’t communicate with the outside world.

(4) Security Groups and Network ACLs are different

 Security Groups control instance traffic. Network ACLs work at the subnet level.

(5) Elastic IPs aren’t unlimited

 AWS allows five per Region by default. Request more if needed.

(6) Flow Logs are a troubleshooting goldmine

 They capture all network traffic, making debugging much easier.

(7) Endpoints save money

 Using VPC Endpoints eliminates the need for costly public internet access.
