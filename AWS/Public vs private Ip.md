what is Public Ip ?

=================

Public Ip is an address of your device on the internet used to identify and access any device from anywhere in the world. It is used on the internet to connect and communicate devices on different networks.

------------------------------------------

what is Private IP ?

==================

Private IP is a local address used for communication between devices inside a network. You cannot access Private IP directly from internet. It works only with in the same network. It is used to connect devices for faster internal communication with in the network. It is used in application servers to communicate with other servers in the same network because Private IP not exposed to internet.
