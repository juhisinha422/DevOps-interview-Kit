Day 14 – AWS VPC (Virtual Private Cloud)

VPC (Virtual Private Cloud) — the networking layer that powers everything in AWS!

🔹 A VPC is your private network in the cloud where you can launch AWS resources securely.

 🔸 It includes key components like:

Subnets (Public & Private)

Route Tables

Internet Gateway (IGW)

NAT Gateway

Security Groups & NACLs

💡 VPC gives you full control over network architecture — IP ranges, access rules, and routing.

📍 Real Use Case:

Host your EC2 instances in a private subnet and expose them through a Load Balancer in a public subnet — secured, scalable, and cloud-native!
