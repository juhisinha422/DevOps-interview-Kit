AWS CLOUDFORMATION

CloudFormation is a service provided by Amazon Web Services (AWS) that enables users to create and manage AWS resources using templates. These templates are written in either JSON or YAML and describe the resources that need to be created, along with their properties and configurations.

🔹 1. Write the Template

 You describe your entire infrastructure in a JSON or YAML file — this becomes your “source of truth.”

🔹 2. Store the Template

 Save it locally or upload to an S3 bucket so CloudFormation can access it easily.

🔹 3. Create a Stack

 A “stack” is a deployment of the template. One click — and AWS starts provisioning.

🔹 4. Automatic Resource Creation

 CloudFormation builds all your resources predictably, repeatedly, and error-free.
