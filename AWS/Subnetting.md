# This cheat sheet breaks down every IPv4 subnet mask from a /32 down to a /0, listing:

⊛ subnet mask: the classic decimal representation.

⊛ CIDR notation: the compact bit count.

⊛binary notation: the full 32-bit pattern, perfectly visualizing the network and host portions.

⊛ available addresses per subnet: the exact number of hosts you can accommodate.

➢ whether you're a seasoned network architect, a sysadmin designing a new network segment, a cloud engineer configuring security groups, or a student prepping for a CCNA, having a clear, definitive reference is invaluable. it saves time, reduces errors, and helps you make better-informed infrastructure decisions.
