Whenever we visit any website (devops.com), the request goes through multiple steps:

🔹 𝗕𝗿𝗼𝘄𝘀𝗲𝗿 𝗖𝗮𝗰𝗵𝗲

Browser checks first here, if it already knows the IP.

🔹 𝗢𝗦 𝗖𝗮𝗰𝗵𝗲

If not found, it checks in Host file, Local cache or system cache.

🔹 𝗜𝗦𝗣 𝗗𝗡𝗦 𝗥𝗲𝘀𝗼𝗹𝘃𝗲𝗿.

Next it checks in your ISP's DNS resolver and its Cache.

🔹 𝗥𝗼𝗼𝘁 𝗦𝗲𝗿𝘃𝗲𝗿𝘀

If still unresolved, it will check in root servers which provides the right TLD's (.com, .org, .edu etc)

🔹 𝗧𝗟𝗗 𝗦𝗲𝗿𝘃𝗲𝗿𝘀

These servers forward the query to the right authoritative DNS servers.

🔹 𝗔𝘂𝘁𝗵𝗼𝗿𝗶𝘁𝗮𝘁𝗶𝘃𝗲 𝗦𝗲𝗿𝘃𝗲𝗿𝘀

These Servers will provides the IP address for the domain devops.com.

👉 𝗞𝗲𝘆 𝗧𝗮𝗸𝗲𝗮𝘄𝗮𝘆: 

From cache to authoritative servers, all of this resolution happens in just milliseconds—and once the IP is found, it gets updated across the respective caches for faster DNS queries.
