Ever wondered how your applications get their configuration in Kubernetes?

Meet:

- 𝐂𝐨𝐧𝐟𝐢𝐠𝐌𝐚𝐩𝐬: for plain text config (like environment variables, app settings)

- 𝐒𝐞𝐜𝐫𝐞𝐭𝐬: for sensitive data (passwords, tokens, API keys)

Both are used to decouple config from your pods, keeping your containers clean and environment-aware.

But here’s the catch:

👉 ConfigMaps are not encrypted

👉 Secrets are base64-encoded, not encrypted by default either, so you still need to enable encryption at rest (especially in production!).

💡 Pro Tip: Never hardcode secrets into your images. Use kubectl create secret or an external secrets manager!
