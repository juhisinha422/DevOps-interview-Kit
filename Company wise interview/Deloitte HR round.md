# 7. Scenario-Based Question (Screenshot Question)

### Question

Suppose a production deployment fails during business hours. What will you do?

### Answer

My first priority would be minimizing customer impact. I would immediately verify the deployment status, review Jenkins pipeline logs, Kubernetes Events, application logs, and monitoring dashboards to identify the issue. If the new deployment is causing failures, I would perform a rollback using Kubernetes Rollout Undo or switch traffic back using Blue-Green deployment if available.

Once production is stable, I would communicate the status to stakeholders, perform Root Cause Analysis, document the findings, implement preventive measures, validate the fix in lower environments, and then schedule a safe redeployment.
